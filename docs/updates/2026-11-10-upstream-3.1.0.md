- Se retiró el pool local de capturas con reutilización automática durante 15 minutos: upstream incorpora gestión de capturas pendientes y memoria de pantallas. Se evita enviar adjuntos viejos en cada pregunta.
- Se combinaron el progreso de audio local con los nuevos avisos de STT/paquetes de upstream.
- La recuperación MCP empieza después de asignar el ID del stream y respeta la cancelación/reemplazo de preguntas.
- El borrado de modos utiliza el diálogo interno existente, conservando la confirmación sin abrir una ventana nativa bloqueante.
- Los helpers de transcripción mantienen la deduplicación local e incorporan la sustitución de parciales de modelos locales de upstream.
- La comprobación central de Pro/trial de upstream se usa cuando están instalados los módulos privados; el backend independiente de conocimiento local sigue disponible cuando no están.

Los submódulos privados `premium` y `natively-api` no están inicializados en este checkout; no se descargaron ni sustituyeron por implementaciones inventadas. Se conserva el fallback local existente.
